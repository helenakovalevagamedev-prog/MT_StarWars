# Test Task

Unity version: 6000.2.6f2
Platform: Android
Orientation: Portrait

## How to run
- Open MainScene
- Press Play

## Implemented features
- Implemented features
- Level system
- Randomized level parameters
- Save / Load system
- Level data persists between sessions
- Completed levels are regenerated
- Sequential level unlocking
- Score tracking and UI display
- Lives tracking and UI display
- Bullet system implemented using Object Pool
- Enemy system implemented using Object Pool
- Configuration system (Player, Enemies, Levels)
- Level info panel
- Game Over panel
- Core gameplay entities follow MVC pattern (Player, Bullets, Enemies)
- Core non-gameplay systems: Save System, Game Manager, UI Controller
